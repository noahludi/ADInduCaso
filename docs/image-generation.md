# Boceto 3D de AD Indumentaria

Herramienta: `image_gen` integrada, sin CLI ni API externa configurada.

Archivo final en el proyecto: `public/images/buzos-preview.webp`.

Original de la generación: `docs/asset-originals/buzos-preview.png`.

Referencia: las tres fotografías provistas por el usuario, correspondientes al pedido de El Ramblón; el logo de AD se usó como contexto de marca, no como estampado. La vista generada es una visualización, no una fotografía del producto terminado. Las fotos originales recuperadas de la publicación se muestran separadamente.
